# Coded domains

An authoritative interchange vocabulary for #101, distinct from Forge enums and hierarchical Classification taxonomies. CodedDomain identity includes an Identifiers Issuer, context, and key. Code identity includes its domain and exact case-sensitive literal. External identifiers attach through IdentifierSet; spelling, labels, and meaning are not silently normalized or equated across authorities.

DomainRelease records an authority's ordered published release, validity, citation and optional sealed Evidence. CodeRevision pins a release and optional Classification ConceptRevision. A later revision preserves code identity and supersedes the previous meaning at its validFrom instant. Release intervals may overlap to allow parallel supported editions. ReleaseWithdrawal withdraws an exact edition; CodeDisposition retires a literal or names an exact successor revision. Increasing code ordinals prevent replacement cycles within a domain. Consumers explicitly choose replacements; historical references never float.

CodeLabel evolves separately by locale without changing code identity or meaning. ConceptMapping identifies the source code, target concept and asserting authority. Its ordered MappingRevisions pin both meanings and state Equivalent, Narrower or Broader from the source code's perspective. Citations and evidence identify who asserted each mapping and why; similar labels are never evidence of equivalence. New literals are resource facts, so no Forge enum/compiler change is necessary.

CodedDomains.inspect and inspectMapping evaluate exact references at an explicit instant, using half-open validity intervals. They authorize all relevant history reads and fail closed on hidden withdrawals, dispositions and successors. Invalid instants fail validation. These helpers report declared authority facts; they do not verify that a tenant's issuer actually controls an external standard. The application authorizes publishing and binds trusted issuers. Identifier lifecycle remains in Identifiers; adding an identifier does not grant publisher authority.

Illustrative country, currency and industry fixtures contain no licensed standards corpus and claim no ISO/NAICS certification. Consumer fields are typed CodeRevision references; applications constrain the accepted domain for each field. Tests cover memory, SQLite and optional PostgreSQL. No external authority API or provider certification is implied.
