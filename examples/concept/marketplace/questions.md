# Modeling pressure

1. State carries job identity but there is no explicit state-key facet or compiler consumer proving keyed isolation. This is the corpus's primary stateful admission test.

2. Geospatial distance units, matching fairness and stale-location policy are not standardized by expression calls. Compare airline feasibility and manufacturing event-time windows.

No new primitive is proposed. Apply relationship → facet → pattern → domain wrapper before kernel promotion; require cross-domain recurrence, English readability, substitution tests and a compiler consumer.
