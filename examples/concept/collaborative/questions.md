# Modeling pressure

1. One logical producer survives concurrent writers: the users are inputs, and competing document-maintenance owners are rejected. This does not prove convergence or causal history.

2. Hierarchical membership traversal, revocation timing and offline authorization require runtime evidence. Policy expression names alone cannot prove inheritance semantics.

No new primitive is proposed. Apply relationship → facet → pattern → domain wrapper before kernel promotion; require cross-domain recurrence, English readability, substitution tests and a compiler consumer.
