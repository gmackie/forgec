# Modeling pressure

1. Runtime payloads and automation expressions are opaque text because ConceptIR lacks dependent types. Validation against tenant schemas is an interpreter obligation, shared with configurable benefits rules.

2. Policy definitions are runtime data, not compile-time principals or policies. Never infer authorization from user-authored metadata.

No new primitive is proposed. Apply relationship → facet → pattern → domain wrapper before kernel promotion; require cross-domain recurrence, English readability, substitution tests and a compiler consumer.
