# Specialized artifact handoff

The controller sketch explains the typed Process seam; the deployment sketch states unresolved execution assumptions. Neither is executable vendor syntax or an analyzer result. `boundary.json` binds exact Process port IDs; the root handoff index pins file digests. A consumer must also pin tool/version/options, domain requirements, target platform, input assumptions and resulting reports before making any verification claim.

A changed artifact digest invalidates any earlier analysis receipt. Passing JSON/reference checks only establishes that this handoff names existing declarations and files. It does not establish behavioral equivalence between the sketch, generated code and hardware.
