# Falsifiable questions

1. Can collection prove every expected member was resolved, rather than merely counting returned jobs? Duplicate successful retries must not fill a missing member.
2. Which input, executable, compiler, library, GPU and random-state digests are needed for the declared equivalence policy? A container digest alone is insufficient evidence of numerical equivalence.
3. Does a preempted attempt's checkpoint belong to the exact member/protocol revision? Reject cross-member and stale-build resumes.
4. If an adaptive sweep chooses new parameters from earlier results, which choice is scientific protocol and which is queue strategy? Revise Experiment rather than hiding an altered hypothesis in L1.
5. Can retries produce different numerical results? Preserve every attempt and publish a deterministic selection policy instead of calling the last finisher authoritative.
6. What analyzer or empirical comparison would support the solver's stability/convergence claim? Record that external evidence independently of a successful HPC exit status.
