Risks & Mitigations

The console never receives runtime credentials. Runtime calls stay on configured endpoints and reject redirects. Deployment actions use idempotency IDs and compare the active deployment. Release images are prepared by the operator pipeline and pinned by digest; the controller does not execute browser-supplied shell commands. Data stores remain external and retained; rollback does not reverse schema migrations.
