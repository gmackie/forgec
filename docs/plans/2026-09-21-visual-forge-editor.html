Overview

A structured visual document for creating and modifying .forge files. Resource cards, field controls, nested capabilities and purpose bindings are direct projections of the real Forge syntax tree. A relationship graph and synchronized source view support the document.

Goals & Non-goals

Open and create files; edit declarations, fields, Forge taxonomy classifications, purposes and explicit capability bindings; inspect relationships and real compiler diagnostics; undo and redo; download edited source. Preserve comments and unedited constructs. Use Kumo for controls, labels as well as color, clear type and nesting hierarchy.

External dependency resolution, collaborative editing and Git synchronization are follow-up work. Existing app configuration and OCI registry remain supporting tools. Compilation happens locally in a browser worker, using the Rust parser and compiler compiled to WebAssembly.

Risks & Mitigations

  • Lossy regeneration: patch precise source ranges rather than regenerate entire files.
  • Unicode spans: translate compiler byte offsets to browser UTF-16 offsets.
  • Incomplete syntax: preserve source and report diagnostics; unsupported constructs retain source editing.
  • Browser responsiveness: compile off the main thread, reject stale results and bound source size.
  • Governance drift: obtain taxonomy from the same compiler; purpose inheritance never implies a grant.
