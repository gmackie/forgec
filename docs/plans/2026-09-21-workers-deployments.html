Risks & Mitigations

Worker names are unique per deployment. The runner journals ownership before upload and removes interrupted candidates on startup. Only owned workers.dev endpoints are toggled; no unrelated Workers or DNS records change. OAuth credentials stay in a private writable volume so Wrangler can refresh them. Noninteractive API tokens are also supported.

Verification

Provider tests, console suite and build, Docker regression, Worker dry run, live success/error invocations and lifecycle checks, then repository CI.

Open Questions

None blocking. Workers are the preferred target; existing Docker support remains available.
